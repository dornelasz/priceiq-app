PRICEIQ — VERSÃO GEMINI

1. Extraia este ZIP no computador.
2. Abra o terminal dentro da pasta.
3. Rode:
   npm install
   npx cap add android
   npx cap sync android
   npx cap open android

4. No Android Studio:
   Build > Build Bundle(s) / APK(s) > Build APK(s)

O APK deve aparecer em:
android/app/build/outputs/apk/debug/app-debug.apk

IMPORTANTE:
- No app, vá em Configurações e cole a Gemini API Key.
- Sem a chave, a busca automática não funciona.
- A busca usa Gemini + Google Search grounding.
- IA por busca web reduz erros, mas não garante 100% de precisão. Sempre confira preços importantes no link do produto.
