Esta versão legada foi desativada

Esta página era o antigo PriceIQ single-file (HTML + JS) com "Captura assistida", "Colar texto", "Colar link" e modo "Manual". Esse fluxo não é mais usado.

O PriceIQ agora é um SaaS com backend dedicado e busca automática via Motor Universal V2 (sem captura manual, sem colar texto/link).

Onde está o app real:

  • Frontend SaaS: web/ (Next.js 14, hospedado na Vercel)
  • Backend SaaS: server/ (Fastify + Postgres, Render)
  • APK Android: wrapper Capacitor que abre a URL real da Vercel

O código legado continua preservado em legacy/index.html apenas para referência histórica — não é a entrada do app.

Detalhes em docs/deployment-entrypoint.md no repositório.
