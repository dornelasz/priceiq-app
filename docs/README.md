# Docs — PriceIQ

Documentação técnica e ADRs (Architecture Decision Records).

## Conteúdo

- [`architecture.md`](./architecture.md) — visão geral da arquitetura SaaS-alvo
- ADRs serão adicionados em `docs/adr/` à medida que decisões forem tomadas

## Convenção de ADRs

Cada ADR documenta uma decisão arquitetural relevante. Formato:

```
docs/adr/0001-titulo-da-decisao.md
```

Estrutura mínima:
- **Contexto:** o que motivou a decisão
- **Decisão:** o que foi escolhido
- **Consequências:** o que muda
- **Alternativas consideradas:** quais foram descartadas e por quê
